      How It Works

      01
      🔗

      Enter a URL

      Paste any URL you want to verify. PhishGuard never visits the URL — it only analyzes the string itself.

      02
      ⚙️

      Feature Extraction

      33 structural and lexical features are extracted: URL length, subdomain count, suspicious keywords, TLD type, entropy, and more.

      03
      🤖

      ML Classification

      An XGBoost model trained on 235,000 labeled URLs classifies the URL as phishing or legitimate with a confidence score.

      04
      💡

      Explainable Result

      SHAP values identify which features contributed most to the prediction — so you understand exactly why the decision was made.
