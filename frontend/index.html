      The Pipeline

      How It Works

      Four stages, one pass. PhishGuard analyzes the URL string alone — no page visits, no DNS lookups, no network calls of any kind.

      1. 01

        Input

        Enter a URL

        Paste any URL. Missing https:// is added, unsafe schemes such as file: or javascript: are rejected, and the string is normalized into a canonical form ready for analysis.

      2. 02

        Extract

        Feature Extraction

        33 deterministic features are pulled straight from the URL string. Length and structure, suspicious keywords and TLDs, brand-spoofing and typosquatting, raw IP hosts, encoding tricks, and the entropy of the URL and its domain.

      3. 03

        Classify

        ML Classification

        An XGBoost model trained on 468,783 labeled URLs predicts the phishing probability. An isotonic calibrator then converts that raw score into an honest confidence, and deterministic brand / whitelist overrides are applied.

      4. 04

        Explain

        Explainable Result

        SHAP values trace which features pushed the verdict toward phishing or legitimate, ranked by impact — so you understand exactly why the decision was made, not just what the answer is.

      Under the Hood

      What PhishGuard inspects

      URL Structure
      Length, dot and slash density, subdomains, ports, path tokens, digits and special characters.
      Domain Reputation
      Trusted apex-domain whitelist, brand-spoofing and typosquatting, raw IP hosts, IPv6 and punycode.
      Lexical Signals
      Suspicious keywords and TLDs, URL shorteners, percent and hex encoding tricks.
      Obfuscation
      High URL and domain entropy, https faked inside the path, abnormal character patterns.
